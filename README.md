# Benj & Rosette Wedding

Wedding invitation for December 15, 2026, 2 PM in Cavite. Hosted with GitHub Pages from the main branch root.

The website uses a flat file layout. Keep all images beside index.html. Set the deployed Google Apps Script /exec URL in rsvp-config.js to activate RSVP spreadsheet saving and calendar invitations. Until configured, replies are downloaded for guests to share with the couple.
